# Modern tarot sources that may allow commercial reuse

Research date: 2026-10-12. A research agent compiled this for Dolores Puckett. It is research, not legal advice. No one was contacted. Anything that could not be checked is marked UNVERIFIED.

## Bottom line

- Only two kinds of modern source clearly allow commercial use, and neither fits the Waite/Golden Dawn tradition well:
  - **the Tarotoo dataset** (MIT licence);
  - **Wikipedia and Wikiversity text** (CC BY-SA licence, which comes with "share-alike" strings).
- Every well-known tarot site that was checked refuses commercial reuse or says nothing: Biddy Tarot, Labyrinthos, Tarot.com, Joan Bunning, Aeclectic and Mary Greer.
- No open-licensed collection of spreads was found.

### Licence terms used below

- **MIT** = a permissive software licence. It allows commercial use and changes. You must keep its copyright notice.
- **CC BY-SA** = a Creative Commons licence. It allows commercial use and changes. You must give credit, and anything you build from it must carry the same licence ("share-alike").
- **NC** = non-commercial only. **ND** = no changes allowed.

## Allowed for commercial use

| Source | Covers | Licence | Fit | Catch |
|---|---|---|---|---|
| Tarotoo Tarot Card Meanings Dataset (2026), https://github.com/Tarotoo-com/tarotoo-tarot-dataset | All 78 cards, upright and reversed, plus keywords and love/career fields. No spreads. | MIT: "free to use, copy, modify, and redistribute, including commercially." | Medium | Its README says the text "was initially generated by Tarotoo using generative AI", then reviewed and edited. The sources used to guide the AI are not named. The love/career/mood fields are AI-written modern extensions. |
| Wikipedia card articles, e.g. https://en.wikipedia.org/wiki/The_Tower_(tarot_card) | Short history and symbolism for each card. This is unresolved for AI output, so ask a lawyer before using it in paid readings. |
| Wikiversity "Tarot Reading", https://en.wikiversity.org/wiki/Tarot_Reading | Rider–Waite meanings for every card, upright and reversed, in a personal "you" voice | Probably CC BY-SA (UNVERIFIED: the page footer was not read) | Medium-low | Anonymous author. It draws on "the literature that accompanies the pack", which may include copyrighted booklets. |

Wikibooks "Tarot" (https://en.wikibooks.org/wiki/Tarot) is mostly empty pages, so it is not worth using.

## Looks free, but must NOT be used

- **Joan Bunning, *Learning the Tarot*** (https://www.learntarot.com/copy.htm). Personal, non-commercial, offline use only; "may not be … incorporated in commercial documents or products". It is the best fit with Waite, so it is worth asking her for permission.
- **Biddy Tarot.** Its terms forbid even "paraphrasing or summarizing content for use in … apps".
- **Labyrinthos** (https://labyrinthos.co/pages/terms-of-service). Personal, non-commercial use only, unless they give written consent in advance.
- **Tarot.com** (https://www.tarot.com/terms-of-use). Commercial use is "expressly prohibited".
- **Aeclectic Tarot.** "All rights reserved."
- **Mary K. Greer.** Her blog material is copyrighted. One informal reply to a single blogger asked only for credit and a link, but that is not a licence.
- **Tarot Association** (Marcus Katz) note: publishers expect automated reading software to be licensed when it uses their deck **art**. This app uses the public-domain 1909 art, so it is not affected, but it must not use any other deck's images.

## Could not verify

- Wikiversity and Wikibooks licence footers.
- Other GitHub datasets that are said to be MIT or CC0. The key question for each is where its meanings text came from.
- Tarotoo's open-data page (it would not load).
- Whether a bare spread layout can be copyrighted. The agent's understanding is that positions and their names are a method, not protected wording. This was not researched, so confirm before copying any author's wording or diagrams.
